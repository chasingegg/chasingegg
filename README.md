## Open-source highlights

- [Faiss](https://github.com/facebookresearch/faiss) — efficient similarity search and clustering for dense vectors
- [Milvus](https://github.com/milvus-io/milvus) — a cloud-native vector database built for scalable ANN search
- [Knowhere](https://github.com/zilliztech/knowhere) — Milvus's vector search engine, integrating FAISS, HNSW, DiskANN, and other indexing technologies
- [VectorDBBench](https://github.com/zilliztech/VectorDBBench) — an open-source benchmarking tool for vector databases
- [Winconv](https://github.com/chasingegg/Winconv) — a C++ implementation of the Winograd minimal convolution algorithm for Intel architecture
